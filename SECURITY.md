# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly.

1. **Do not** open a public issue.
2. Email your findings to the repository owner through [GitHub's security contact form](https://github.com/SalauddinAhmad/tech-blog/security/advisories/new).
3. Include as much detail as possible: steps to reproduce, affected versions, and potential impact.

The maintainer will acknowledge receipt within 48 hours and work on a fix. Once resolved, a security advisory will be published.

## Supported Versions

Only the latest commit on `main` receives security updates.
