### 🚀 স্থানীয় ডেভেলপমেন্ট

**পূর্বশর্ত:** Hugo Extended ইনস্টল থাকতে হবে

```bash
# রিপো ক্লোন করুন
git clone https://github.com/SalauddinAhmad/tech-blog.git
cd tech-blog

# ডিপেন্ডেন্সি ইনস্টল
hugo mod get

# লোকাল সার্ভার চালু (ড্রাফট সহ)
hugo server -D
```

সার্ভার চলবে <a href="http://localhost:1313"><code>http://localhost:1313</code></a>
